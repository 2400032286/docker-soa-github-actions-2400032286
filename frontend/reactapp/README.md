# Home Cleaning Booking – React Frontend

This frontend follows the same Vite + React project structure as the supplied `frontend/reactapp` project and is adapted to the `HomeCleaningBooking` entity.

## Entity fields
- `id` – generated by the backend; not entered in the Add Booking form
- `customerName`
- `bookingDate`
- `serviceFee`
- `completed`

## Run
1. Start the Spring Boot backend on `http://localhost:8080`.
2. Open a terminal in `frontend/reactapp`.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the Vite URL shown in the terminal (usually `http://localhost:5173`).

The frontend calls these backend endpoints:
- `POST /homecleaningbooking/add`
- `GET /homecleaningbooking/displayall`
- `GET /homecleaningbooking/display/{id}`
- `PUT /homecleaningbooking/update/{id}`
- `DELETE /homecleaningbooking/delete/{id}`

If your backend uses a different port, update `API_URL` in `src/pages/BookingService.js`.


### UI framework
This frontend uses Bootstrap 5.3 CSS from the official jsDelivr CDN alongside the existing project styles for responsive forms, buttons, alerts, and tables. An internet connection is required for the Bootstrap stylesheet.
